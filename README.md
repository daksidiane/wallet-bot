# Telegram-бот для учёта финансов

Проблема бизнеса: Заполнять таблицы с формулами с телефона было неудобно. Доходы и расходы записывали в разных местах, баланс сводили вручную.

Бот принимает текст с приходом или расходом, раскладывает по категориям, собирает выписку за период и следит за лимитами и целями накоплений.

Владелец ведёт статистику по счетам в мессенджере. Бюджет и прогресс по цели видны без таблиц на маленьком экране.

## Установка и запуск

Нужны Windows, PHP 8 или новее в PATH и токен бота от [@BotFather](https://t.me/BotFather).

```cmd
copy bot\secrets.example.php bot\secrets.php
```

В `bot/secrets.php` вставьте токен:

```php
'telegram_bot_token' => 'ТОКЕН_ОТ_BOTFATHER',
```

Запуск:

```cmd
start.bat
```

Или из папки `bot/` — `start.bat`. Остановка: Ctrl+C.

База создаётся при первом запуске. Готовый PHP в эту копию не входит: поставьте PHP 8+ и добавьте его в PATH либо положите `php.exe` в `bot/php/`.

## Как пользоваться

1. Напишите боту пополнение или списание и категорию.
2. Запросите баланс — это поступления минус расходы.
3. Листайте историю операций.
4. При необходимости задайте лимит трат и цель накоплений — бот напомнит, когда порог достигнут.
