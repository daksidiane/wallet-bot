# Telegram-бот для учёта финансов

Заполнять таблицы с формулами с телефона было неудобно. Доходы и расходы записывали в разных местах, баланс сводили вручную.

Бот принимает текст с приходом или расходом, раскладывает по категориям, собирает выписку за период и следит за лимитами и целями накоплений.

Владелец ведёт статистику по счетам в мессенджере. Бюджет и прогресс по цели видны без таблиц на маленьком экране.

## Как попробовать

Нужны Windows, Telegram и программа [PHP 8](https://windows.php.net/download/). Подойдёт и пакет [XAMPP](https://www.apachefriends.org/) — там PHP уже внутри.

1. На этой странице нажмите **Code** → **Download ZIP** и распакуйте архив.
2. Создайте бота в Telegram: [@BotFather](https://t.me/BotFather) → `/newbot`. Сохраните токен.
3. В папке `bot` скопируйте файл `secrets.example.php` и назовите копию `secrets.php`.
4. Откройте `secrets.php` блокнотом. В кавычки после `telegram_bot_token` вставьте токен. Сохраните.
5. Вернитесь в распакованную папку проекта и дважды щёлкните `start.bat`.

Если чёрное окно пишет, что PHP не найден: поставьте PHP 8, при установке включите добавление в PATH, **закройте** чёрное окно и снова запустите `start.bat`.

Остановка: закройте чёрное окно или нажмите в нём Ctrl+C.

6. В Telegram найдите своего бота и напишите ему.

## Как пользоваться

1. Напишите пополнение или списание и категорию, например: «расход 500 такси».
2. Спросите баланс.
3. Листайте историю операций.
4. Если зададите лимит трат или цель накоплений, бот напомнит, когда порог достигнут.
