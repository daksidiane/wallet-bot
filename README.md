# Telegram-бот: Личный финансовый трекер и учет баланса (MVP)

Telegram-бот для персонального учета финансов: баланс равен пополнениям минус списания, есть история операций и категории.

---

## 🚀 Быстрый запуск

1. Перейдите в папку `bot/` (или запустите `start.bat` из корня).
2. Откройте `bot/secrets.php` и вставьте ваш токен Telegram-бота:
   ```php
   'telegram_bot_token' => 'ВАШ_ТОКЕН_ОТ_BOTFATHER',
   ```
3. Запустите бота двойным кликом по `start.bat`.
   - В проект уже встроен портативный PHP 8, никаких дополнительных установок не требуется.
   - База данных SQLite с тестовыми транзакциями уже инициализирована в `bot/db/wallet.sqlite`.

---

## 🔒 Безопасность (Zero-Leak Policy)
- Файл `secrets.php` содержит плейсхолдер `PASTE_TOKEN_FROM_BOTFATHER`.
- Личные токены и авторизационные данные вычищены перед отправкой на проверку.
